## About the Project

I recently started learning backend development and explored the fundamentals of **Node.js, Express.js, and MongoDB**. After learning the basics of **CRUD operations**, I built this project to practice and strengthen my backend development skills.

This project is a simple **User Management System** that implements basic CRUD operations such as creating, reading, updating, and deleting users.

# User Management CRUD

## Features
- Create User
- View Users
- Update User
- Delete User

## Tech Stack
- React
- Axios
- Express.js
- MongoDB
- Mongoose

## API Routes
POST   /create
GET    /read
PATCH  /users/:id
DELETE /users/:id
